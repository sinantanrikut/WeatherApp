# WeatherApp

WeatherApp is a SwiftUI application that allows users to save and view their favorite cities' weather information. The app utilizes Firebase for user authentication and data storage, providing a seamless experience for managing city data.

## Features

- **User Authentication**: Users can sign in to manage their favorite cities.
- **City Management**: Add or remove cities from the list.
- **Weather Information**: Display detailed weather data for each city (to be implemented).
- **Responsive Design**: Built with SwiftUI for a smooth user interface.

## Technologies Used

- SwiftUI
- Firebase (Firestore and Authentication)
- Xcode

## Installation

1. Clone the repository:
   ```bash
   [git clone https://github.com/sinantanrikut/WeatherApp.git](https://github.com/sinantanrikut/WeatherApp.git)
   
2. Open the project in Xcode:
   ```bash
   open WeatherApp.xcodeproj
   ```

3. Install the necessary pods (if using CocoaPods) by running:
   ```bash
   pod install
   ```

4. Set up Firebase:
   - Create a Firebase project.
   - Add your app to the project and download the `GoogleService-Info.plist` file.
   - Add the file to your Xcode project.

5. Run the app:
   - Select your simulator or device in Xcode and click the Run button.

## Usage

1. Launch the app.
2. Sign in or create a new account.
3. Enter a city name in the text field and click "Save City."
4. View the list of saved cities, and click on a city to see more details (details to be implemented).
5. Remove a city by clicking the trash icon next to it.
