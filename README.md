# WeatherApp

WeatherApp is a SwiftUI application that allows users to save and view their favorite cities' weather information. The app utilizes Firebase for user authentication and data storage, providing a seamless experience for managing city data.

## Features

- **User Authentication**: Users can sign in to manage their favorite cities.
- **City Management**: Add or remove cities from the list.
- **Weather Information**: Display detailed weather data for each city (to be implemented).
- **Responsive Design**: Built with SwiftUI for a smooth user interface.

## Technologies Used

- SwiftUI
- Firebase (Firestore and Authentication)
- Xcode
